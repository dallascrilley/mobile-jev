## Implementation and checks

The adapter validates the explicit UDID, owner-only endpoint binding, live owned processes, WDA vendor identity, paired/connected CoreDevice state and unlocked WDA state. It uses screen points, rejects stale targets, obtains actual active-field evidence, masks password values, and verifies exact text readback. Native Switch resolution requires exactly one matching name and rectangle. Ambiguous or stale targets cause no click; uncertain click responses are not replayed. Resolution has a total time limit; state, geometry and observation age are checked again before the click. Android-only navigation is rejected; a real in-app Back button remains a valid observed target.

The supervisor refuses occupied ports and foreign/live bindings, derives a per-device runner configuration, creates one session without auto-accepting alerts or resetting user apps, and cleans up its owned children on failure. Credentials go only to the decision service. Runtime and installer HTTP redirects are rejected; 307/308 regression tests confirm zero requests to redirect destinations. Recovery and cancellation reject a supplied wrong device ID before dispatch. The iOS recovery endpoint verifies readiness; launchd owns process restart. Closing Raycast leaves submitted goals running; restarting the service loses in-memory history.

`pnpm check` passed: 167 tests, lint, studio types, formatting and production build. This includes 26 iOS adapter tests and 39 runtime/installer tests. The extension's `npm run check` passed: 50 tests, types, lint, production build and validator. No provisioning shell code changed in this iOS phase. The earlier Android suite, jev-sim's 44 offline tests, provisioning ShellCheck/46 tests and Android extension's 14 tests remain recorded in the Android report.
